## 🧭 制约与誓约 / Vows & Limitations

这里是**奥卡姆的猎人工坊**。我们信奉第一性原理，以奥卡姆剃刀为尺，在自我设定的**“制约与誓约”**下，专注于锻造高效、简洁的现代软件。

制约越严苛，锋芒越纯粹。如今的许多软件背负了太多本不必要的重量——重型框架、强制联网与后台常驻，让本该轻快的工具变得迟钝而喧闹。

我们选择做减法。借助 AI 跨越底层开发的技术门槛，重拾古典软件的克制审美与原生性能，亲手打造“小而美、零云端、用完即走”的工具，把速度、静默与掌控权重新交还给用户。

This is **Ockham's Hunter Workshop**. Guided by first principles, we wield Ockham’s razor under deliberate self-imposed **Vows & Limitations** to craft fast, clean, and purposeful software.

The stricter the constraints, the sharper the edge. Too much modern software carries unnecessary weight—wrapping simple, local tasks in heavy frameworks, mandatory cloud accounts, and constant background activity.

We choose restraint. Leveraging AI to lower the barrier to native development, we return to classic software craftsmanship. We forge small, local-first, zero-friction tools that respect your time, privacy, and hardware.

---

## 📜 工坊四律 / The Four Vows

### 1. 如无必要，勿增实体 (Zero Bloat)
- 拒绝重型套壳框架与冗余运行时依赖。根据目标平台选择最契合的原生技术栈，追求极致的启动速度、包体控制与内存效率。
- *Avoid heavy wrappers and redundant runtimes. Choose the right native stack for each platform to achieve instant startup, minimal footprint, and high efficiency.*

### 2. 数据归用户，本地优先 (Local-First)
- 核心功能在离线状态下 100% 完整可用。不收集遥测数据，不强制绑定账号，把数据所有权与隐私安全留给用户自己。
- *100% of core features work completely offline. No telemetry, no forced accounts—your data stays strictly on your device.*

### 3. 纯粹拥有，无套路 (Own Forever)
- 远离复杂订阅、功能锁与诱导弹窗。开源代码在 GitHub 免费共享；即便未来上架应用商店，也坚持透明的一次性买断或纯自愿打赏。
- *Free from dark patterns, feature locks, and subscriptions. Open-source on GitHub; any store releases remain simple one-time purchases or voluntary donations.*

### 4. 神速执行，保持静默 (Godspeed & Zero Friction)
- 砍掉社区、资讯、打卡等一切与核心功能无关的干扰。如神经反射般瞬间启动，完成任务即刻退出，空闲时保持 0% CPU 的绝对安静。
- *No feeds, badges, or background clutter. Launch with reflex-like speed, finish the job, and exit cleanly—leaving zero background footprint.*

## 🛠️ 兵器图鉴 / Forged Weapons

### ⚡ 1. GeekDeskCpp
> **[桌面启动器] 极致轻量化的 Windows 桌面快捷启动与管理工具。**
- 🧩 使用原生 C++ 对经典 WPF 启动器进行全面重构。
- 📦 **2.65 MB** 单文件可执行程序，日常驻留内存仅 **22–24 MB**，闲置 CPU 0%。
- 🔗 [仓库地址 / Repository](https://github.com/OckhamsHunterWorkshop/GeekDeskCpp)

### 📷 2. OpenScanner (锻造中 / Work In Progress)
> **[极简原生文档扫描仪] 无水印、纯本地、零冗余的跨平台原生扫描工具。**
- 🧩 共享纯 C++17 核心图像处理引擎，搭配 Kotlin (Android) 与 Swift (iOS) 原生界面。
- 🔒 Android 端**不声明 INTERNET 网络权限**，从系统底层保障离线隐私。
- ⚡ 包体控制在 **8 MB 以内**，冷启动毫秒级直达取景框；支持自动切边拉正、去阴影纸底漂白，一键导出无水印 PDF 并调用系统分享。
- 🔗 仓库即将公开 / Repository opening soon.
