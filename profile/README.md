## 🧭 我们的誓约与制约 / Our Vows & Limitations

这里是**奥卡姆的猎人工坊**。我们秉承第一性原理，挥起奥卡姆剃刀，并在严格的自限（制约与誓约）下，为对抗现代软件的畸变而默默锻造。

当下的商业软件已沦为吞噬内存、电量与隐私的臃肿巨兽。本可在本地毫秒级解决的基础任务，被强行塞入重型跨平台框架（Electron, Flutter）、强制联网账号、弹窗广告与云端寄生，并通过连续订阅向用户永久收租。

我们不当被收割的猎物。我们借助 AI 消除开发门槛，重回古典极客审美与原生 C/C++。我们亲手锻造“小而美、零云端、用完即走”的手术刀级兵器，斩断数字臃肿，将软件所有权与设备性能彻底还给用户。

This is **Ockham's Hunter Workshop**. Driven by first principles, we wield Ockham’s razor under strict self-imposed constraints (Vows & Limitations) to forge weapons against the grotesque bloat of modern software.

Modern commercial software has degenerated into memory-hogging, telemetry-bloated monstrosities. Simple tasks that should take milliseconds locally are wrapped in heavy cross-platform frameworks, forced online accounts, trackers, and subscription paywalls.

We refuse to be the prey. Wielding AI to dismantle development barriers, we return to classic hacker aesthetics and native C/C++ code. We forge "small, local-first, zero-friction" surgical instruments to slice through digital bloat, restoring ownership and device performance back to the user.

## 📜 工坊铁律 / The Workshop Laws

### 1. 如无必要，勿增依赖 (Zero Bloat)
* 严禁 Electron, Flutter, React Native 等重型套壳与冗余运行时。
* 优先使用原生 C/C++ 压榨硬件，追求极致体积与内存控制。
* *No heavy wrappers (Electron/Flutter) or bloated runtimes. Prioritize native C/C++ to extract maximum hardware efficiency with minimal footprint.*

### 2. 数据归用户，不归云端 (Local-First)
* 100% 核心功能必须在断网状态下完备运行。从物理和权限上杜绝隐私泄露与强制同步。
* *100% core features must run fully offline. Zero unauthorized telemetry, zero forced cloud syncing.*

### 3. 一次拥有，拒绝绑架 (Own Forever)
* 彻底消灭订阅、自动续费与功能锁。
* 代码在 GitHub 永远开源免费；商店上架采用极低价一次性买断或纯自愿打赏。
* *Eradicate subscriptions, dark patterns, and paywalls. Code remains open and free; app store releases are cheap one-time buys or purely donation-based.*

### 4. 用完即走，尊重静默 (Godspeed & Zero Friction)
* 如同暗杀者的信条——启动即干活，干完即退出，不留痕迹，空闲时保持 0% CPU 绝对静默。
* 绝无社区、资讯、弹窗、打卡等伪需求。
* *Like an assassin—launch instantly, complete the task, exit immediately. Absolutely zero background footprint, zero push notifications, and zero feature creep.*
