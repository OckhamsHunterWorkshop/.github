## 🧭 制约与誓约

这里是**奥卡姆的猎人工坊**。我们信奉第一性原理，以奥卡姆剃刀为尺，在**制约与誓约**下，专注于锻造高效、简洁的现代软件。

制约越严苛，锋芒越纯粹。如今的许多软件背负了太多本不必要的重量——重型框架、强制联网与后台常驻，让本该轻快的工具变得迟钝而喧闹。

我们选择做减法。借助 AI 跨越底层开发的技术门槛，重拾古典软件的克制审美与原生性能，亲手打造“小而美、零云端、用完即走”的工具，把速度、静默与掌控权重新交还给用户。

---

## 📜 工坊四律

### 1. 如无必要，勿增实体 (Zero Bloat)
- 拒绝重型套壳框架与冗余运行时依赖。根据目标平台选择最契合的原生技术栈，追求极致的启动速度、包体控制与内存效率。

### 2. 数据归用户，本地优先 (Local-First)
- 核心功能在离线状态下 100% 完整可用。不收集遥测数据，不强制绑定账号，把数据所有权与隐私安全留给用户自己。

### 3. 纯粹拥有，无套路 (Own Forever)
- 远离复杂订阅、功能锁与诱导弹窗。开源代码在 GitHub 免费共享；即便未来上架应用商店，也坚持透明的一次性买断或纯自愿打赏。

### 4. 神速执行，保持静默 (Godspeed & Zero Friction)
- 砍掉社区、资讯、打卡等一切与核心功能无关的干扰。如神经反射般瞬间启动，完成任务即刻退出，空闲时保持 0% CPU 的绝对安静。
